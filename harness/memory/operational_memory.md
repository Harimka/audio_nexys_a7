# OPERATIONAL MEMORY: AUDIO NEXYS A7 PROJECT CONTEXT

## Project Baseline Context
- Repository: `audio_nexys_a7`
- Device: Xilinx Artix-7 `xc7a100tcsg324-1`
- Reference Clock: 100 MHz oscillator (`sys_clk`)
- Clocks generated by `clk_wiz_0`:
  * `clk_audio`: ~49.152 MHz (or 49.157 MHz) for audio DSP
  * `clk_vga`: 50 MHz for 800×600 @ 72 Hz VGA display
  * Sample rate: ~48,006.5 Hz derived via accumulator
  * PWM resolution: 10-bit

## Known Baseline Defects (Reproduced in `tests/audit/audit_tb.sv`)
1. **Reset Loss-of-Lock Defect (`reset_button_debouncer.sv`)**:
   - Issue: When the PLL loses lock (`locked == 0`), `rst_n` remains high (`1`) instead of dropping to active-low reset (`0`).
   - Fix target: Synchronously force `rst_n <= 1'b0` whenever `locked == 1'b0`, and re-debounce or delay release after lock is regained.

2. **VGA VS Front Porch Defect (`display_ctrl.sv`)**:
   - Issue: Vertical Sync (`VS`) signal transition occurs with an offset of 2,110 pixel clocks compared to the configured front porch lines.
   - Fix target: Correct the vertical line counter / comparator timing in `display_ctrl.sv` to align VS strictly with 800×600 @ 72 Hz timing standards.

3. **Missing Port Elaboration in Original Testbench (`tb_audio_nexys_a7.sv`)**:
   - Issue: Wildcard instantiation `.*` fails elaboration in Icarus Verilog because VGA port connections are missing in the testbench top.
   - Fix target: Explicitly bind or stub unused top-level ports in testbenches.
