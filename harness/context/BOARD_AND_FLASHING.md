# АППАРАТНАЯ ПЛАТФОРМА NEXYS A7-100T И РАБОТА С ПРОШИВКОЙ

Этот документ фиксирует аппаратную структуру платы **Digilent Nexys A7-100T**, все доступные интерфейсы, правила электробезопасности и инструкцию по созданию и загрузке прошивки (битстрима).

---

## 1. Обзор аппаратной платформы

| Узел платы | Характеристики | Как подключен к FPGA |
|---|---|---|
| **ПЛИС (FPGA)** | Xilinx Artix-7 `XC7A100T-1CSG324C` | 101,440 логических ячеек, 4,860 Кбит BRAM (~607 КБ), 240 DSP-слайсов |
| **Опорный генератор** | 100.0 МГц, 3.3V | Пин **`E3`** (`CLK100MHZ`), стандарт `LVCMOS33` |
| **Аудиовыход 3.5 мм** | Моно ШИМ-аудио с фильтром НЧ и усилителем | Пин **`A11`** (`AUD_PWM`), Пин **`D12`** (`AUD_SD` — включение усилителя) |
| **Видеовыход VGA** | 12-битный цвет (4096 цветов), разъем DB15 | 12 линий цвета + `VGA_HS` (**`B11`**), `VGA_VS` (**`B12`**) |
| **Кнопки** | 5 пользовательских + 1 аппаратный сброс | `BTNC` (**`N17`**), `BTNU` (**`M18`**), `BTNL` (**`P17`**), `BTNR` (**`M17`**), `BTND` (**`P18`**); Red `CPU_RESETN` (**`C12`**, активный 0) |
| **Переключатели (Switches)** | 16 тумблеров `SW[15:0]` | `SW[0..15]`, верхние пины `J15`..`V10` |
| **Светодиоды (LEDs)** | 16 зеленых + 2 RGB | `LED[0..15]`, `LED16_RGB`, `LED17_RGB` (в демо закомментированы в XDC) |
| **7-сегментный дисплей** | 8 разрядов с динамической индикацией | Катоды сегментов `CA..CG, DP`, аноды разрядов `AN[7:0]` |
| **Слот MicroSD** | Слот для карт памяти SD/SDHC/SDXC | Поддерживает режим SPI: `SD_SCK` (**`B1`**), `SD_CMD/MOSI` (**`C1`**), `SD_DAT[0]/MISO` (**`C2`**), `SD_DAT[3]/CS` (**`D2`**) |
| **Интерфейс USB-UART** | FTDI FT2232HQ (порт Micro-USB `PROG/UART`) | JTAG отладка/прошивка + последовательный порт: `UART_TXD_IN` (**`C4`**), `UART_RXD_OUT` (**`D4`**) |
| **USB Host (HID)** | Контроллер Microchip PIC24 | Эмуляция PS/2 для USB-клавиатуры/мыши: `PS2_CLK` (**`F4`**), `PS2_DATA` (**`B2`**). **USB-MIDI НЕ поддерживается.** |
| **Внешняя память RAM** | 128 МБ DDR2 SDRAM (MT47H64M16HR-25E) | Доступна только через Xilinx MIG IP (16-битная шина, до 333 МГц) |
| **Флеш-память конфигурации**| 16 МБ Spansion Quad-SPI Flash (S25FL128S) | Хранит энергонезависимый битстрим и пользовательские данные |

## 2. Аудиовыход платы (Схемотехника и правила)

Выходной разъем 3.5 мм на Nexys A7 устроен следующим образом:
1. Вывод FPGA **`AUD_PWM` (A11)** через пассивный низкочастотный RC-фильтр 4-го порядка формирует аналоговый сигнал.
2. На плате установлен подтягивающий резистор (Pull-up) к чистой аналоговой шине питания 3.3 В.
3. **КРИТИЧЕСКОЕ ПРАВИЛО:**
   * Когда логика формирует низкий уровень ШИМ — драйвер выдает **`1'b0`** (притягивает к земле).
   * Когда логика формирует высокий уровень ШИМ — драйвер переводится в высокоимпедансное состояние **`1'bz`** (Pull-up платы поднимает напряжение).
   * **Выдача `1'b1` СТРОГО ЗАПРЕЩЕНА**, так как активный драйвер 3.3V нарушает работу аналогового фильтра и может вызвать перегрузку.
4. Вывод **`AUD_SD` (D12)** — активная единица включает выходной аналоговый моно-усилитель платы. При `0` усилитель выключен (режим mute / энергосбережение).

## 3. Где и как хранить музыку на плате

| Тип памяти | Объем | Сложность подключения | Применение для хакатона |
|---|---|---|---|
| **BRAM ПЛИС** | ~607 КБ (4 860 Кбит) | **Минимальная** (читается за 1 такт, инициализируется при синтезе из `.mem` файла) | **Идеально для ROM-мелодий:** хватает на огромный массив нот, аккордов и длительностей (MIDI-подобный секвенсор) либо на ~13 секунд звука 8-бит/48 кГц. |
| **MicroSD карта** | 2 ГБ – 32 ГБ | **Средняя** (требуется контроллер SPI в SystemVerilog, чтение блоками по 512 байт, парсер WAV) | Позволяет проигрывать полноценные песни WAV без ограничений по размеру. |
| **QSPI Flash** | 16 МБ | **Средняя/Высокая** (требуется SPI контроллер для чтения пространства после битстрима) | Энергонезависимое хранение нескольких готовых песен. |
| **DDR2 SDRAM** | 128 МБ | **Высокая** (требуется генерация и настройка IP-ядра Xilinx MIG) | Избыточна без процессора. |

## 4. Процесс сборки и прошивки (Vivado Workflow)

### Шаг 1: Развертывание проекта
Проект создается из корня репозитория:
```bash
make deploy
```
*(Или вручную через консоль Vivado: `vivado -mode tcl -source ./src/tcl/deploy.tcl`).*
> ⚠️ **Важно:** Имя папки репозитория должно оставаться `audio_nexys_a7`, так как Tcl-скрипт определяет имя верхнего модуля автоматически по имени родительской директории.

### Шаг 2: Синтез и генерация битстрима в Vivado GUI
1. Нажать **Run Synthesis**.
2. Нажать **Run Implementation**.
3. Нажать **Generate Bitstream**.
Файл прошивки генерируется по пути: `vivado/audio_nexys_a7.runs/impl_1/audio_nexys_a7.bit`.

### Шаг 3: Прошивка через Hardware Manager
1. Подключить плату кабелем Micro-USB к разъему `PROG / UART` (J6).
2. Включить тумблер питания на плате (`POWER` возле разъема питания).
3. В Vivado нажать **Open Target -> Auto Connect**.
4. Нажать **Program Device**, выбрать `audio_nexys_a7.bit` и нажать **Program**.
Прошивка моментально загружается во внутренний SRAM FPGA (индикатор `BUSY` гаснет, загорается зеленый `DONE`).

### Шаг 4: Энергонезависимая запись в QSPI Flash (Чтобы работало без ПК)
1. В Hardware Manager нажать правой кнопкой на ПЛИС -> **Add Configuration Memory Device**.
2. Выбрать микросхему `s25fl128s-3.3v-qspi-x4-single` (производитель Spansion).
3. Указать сгенерированный `.bin` или `.mcs` файл и нажать **OK**.
4. Установить перемычку выбора режима загрузки `JP1` на плате в положение **QSPI**. Теперь плата запускает плеер автоматически при подаче питания!
