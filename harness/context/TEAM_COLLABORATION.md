# АРХИТЕКТУРА СОВМЕСТНОЙ РАБОТЫ (3 ЧЕЛОВЕКА + AI-АГЕНТЫ)

Этот документ описывает, как организовать параллельную разработку команды из 3 человек с использованием агентных менеджеров (Antigravity, Codex и др.) так, чтобы **никто не блокировал друг друга и не затирал чужой код**.

---

## 1. Принцип изоляции (Code Ownership & Interface Freeze)

Чтобы избежать Git-конфликтов и регрессий:
1. **Жесткое разделение владения файлами:** Каждый файл проекта закреплен ровно за одним человеком и его агентом. Никто другой не коммитит в эти файлы.
2. **Фиксация интерфейсов:** Модули взаимодействуют строго через зафиксированные порты (см. [`INTERFACES_CONTRACT.md`](file:///c:/Users/zeets/VScode/audio_nexys_a7/harness/context/INTERFACES_CONTRACT.md)).
3. **Общий `top.sv` правит только Интегратор:** Другие разработчики передают ему пример инстанцирования своего модуля в виде Pull Request или патча.

---

## 3. Схема работы с Git и слияние изменений

1. Ветка `main` — защищенная базовая ветка.
2. Каждый разработчик создает свою ветку от `main`:
   * `feature/audio-sequencer` (Человек 1)
   * `feature/vga-visualizer` (Человек 2)
   * `feature/periph-and-reset` (Человек 3)
   * `harness(develop)` (Инфраструктурная ветка агентов)
3. **После каждого шага:**
   Запускается Скилл 1 ([`harness/tools/sync_main.py`](file:///c:/Users/zeets/VScode/audio_nexys_a7/harness/tools/sync_main.py)):
   * Анализирует, что нового влито в `main`.
   * Проверяет, нет ли пересечения файлов с другими участниками.
   * Если пересечений нет — подтягивает изменения.
   * Если есть конфликт — останавливается и сигнализирует разработчику.
