# КОНТРАКТ АППАРАТНЫХ ИНТЕРФЕЙСОВ И ШИН (INTERFACES CONTRACT)

Чтобы несколько разработчиков и агентов могли писать модули параллельно без конфликтов в `audio_nexys_a7.sv`, все модули обязаны строго соблюдать данный интерфейсный контракт, адаптированный под спецификацию платы Digilent Nexys A7-100T.

**Статус реализации:** этот документ содержит целевые интерфейсы всей системы. В ветке `future` текущий keyboard prototype — 8 голосов в `clk_audio`, с per-key make/break событиями и signed 20-bit суммой внутри `keyboard_poly_synth`; выход возвращается в unsigned PWM шкалу с midpoint `0x8000`. Он заменяет только плановый 4-голосный микшер на этом этапе. ADSR, VGA waveform buffer и несколько форм волн остаются целевыми частями документа, а не реализованными функциями.

## 1. Тактовые домены и сброс

```
sys_clk (100.0 MHz) ──► [clk_wiz_0] ──┬──► clk_audio  (49.159 MHz) ──► Audio DSP & PWM
                                      ├──► clk_5mhz0d ( 4.993 MHz) ──► Seven-segment & Debouncers
                                      └──► pixel_clk  (39.941 MHz) ──► SVGA 800x600@60Hz Controller
```

| Домен | Частота | Источник | Назначение |
|---|---|---|---|
| `sys_clk` | 100.0 МГц | Входной генератор платы (E3) | Вход для `clk_wiz_0`, debouncer кнопки сброса |
| `clk_audio`| 49.159 МГц | `clk_wiz_0.clk_out1` | Тракт DDS/полифонии, ADSR, микшер, FIFO, PWM генератор (~48.006 кГц sample rate) |
| `clk_5mhz0d`| 4.993 МГц | `clk_wiz_0.clk_out2` | Контроллер 7-сегментных индикаторов, дебаунсеры кнопок |
| `pixel_clk` | 39.941 МГц | `clk_wiz_0.clk_out3` | SVGA 800×600 @ 60.2 Гц видеовывод (пины VGA) |

> [!IMPORTANT]
> **Не менять параметры Clocking Wizard (`clk_wiz_0`):** Частоты фиксированы и согласованы с таймингами развертки 800×600 @ 60 Гц и дискретизацией аудио ~48 кГц. Копировать параметры 50 МГц / 72 Гц или 640×480 из методичек запрещено!

### Контракт сброса:
* **Активный уровень:** Active-low (`rst_n`, 0 = сброс, 1 = нормальная работа).
* **Условие удержания сброса:** Асинхронное выставление `rst_n <= 1'b0` при `!pll_rst_n || !pll_locked`.
* **Синхронизация снятия:** Каждый тактовый домен обязан иметь локальный сброс (`aud_rst_n`, `pix_rst_n`, `rst_n`), снятие которого синхронизировано через 2 триггера (`reset_sync.sv`) с тактовой частотой соответствующего домена.

## 2. Канонические структуры данных (Межмодульный API)

### 2.1. Шина событий ввода (Input Event Bus)
```systemverilog
typedef struct packed {
    logic       valid;       // 1 такт: произошло событие (нажатие/отпускание)
    logic       down;        // 1 = клавиша нажата, 0 = отпущена
    logic [6:0] note;        // 0..127 (MIDI код ноты, например 60 = C4, 69 = A4)
    logic [6:0] velocity;    // 1..127 (сила удара / громкость)
    logic [2:0] wave_type;   // 0=Синус, 1=Пила, 2=Треугольник, 3=Квадрат
    logic [7:0] scancode;    // Исходный скан-код PS/2 (для устойчивой привязки голоса к клавише)
} note_event_t;
```

### 2.2. Аудиопоток синтезатора (Audio Stream Bus)
```systemverilog
typedef struct packed {
    logic signed [15:0] sample;       // 16-битный PCM сэмпл со знаком (-32768 .. +32767)
    logic               sample_valid; // Строб сэмпла (частота 48.006 кГц, 1 такт clk_audio на каждые 1024)
    logic               phase_sync;   // Строб начала периода басовой ноты (Zero-crossing для осциллографа)
} audio_stream_t;
```

### 2.3. Контракт виджета отрисовщика (Widget Render Interface)
Каждый модуль-виджет (`widget_*.sv`) реализует конвейерный интерфейс:
```systemverilog
// Входы: координаты текущего луча монитора (домен pixel_clk)
input  logic [10:0] pixel_x,
input  logic [9:0]  pixel_y,

// Выходы: попадание в виджет и цвет пикселя (12-бит RGB)
output logic        layer_hit,
output logic [11:0] layer_rgb
```

## 3. Видеоинтерфейс (SVGA 800×600 @ 60 Гц)

Контроллер развертки `display_ctrl.sv` работает на частоте `pixel_clk = 39.941 МГц`:

| Параметр развертки | Строка (Горизонталь, пиксели) | Кадр (Вертикаль, строки) | Полярность |
|---|---:|---:|:---:|
| **Видимая зона (Active)** | 800 | 600 | — |
| **Переднее гашение (Front Porch)** | 40 | 1 | — |
| **Синхроимпульс (Sync Pulse)** | 128 (HS) | 4 (VS) | Положительная (1) |
| **Заднее гашение (Back Porch)** | 88 | 23 | — |
| **Полный период (Total)** | **1056** | **628** | — |

* Частота кадров: $39.9414\text{ МГц} / (1056 \times 628) \approx 60.23\text{ Гц}$.

### Конвейерное выравнивание (Pipeline Alignment):
Так как чтение из Block RAM и Font ROM имеет аппаратную задержку в 1 такт (`read latency = 1 cycle`), видеокомпоновщик `ui_compositor.sv` обязан задерживать сигналы синхронизации:
```systemverilog
// Выравнивание задержки синхросигналов под латентность BRAM (1 такт)
always_ff @(posedge pixel_clk) begin
    h_sync_d1 <= h_sync;
    v_sync_d1 <= v_sync;
    disp_enbl_d1 <= disp_enbl;
end
```

## 4. Звуковой тракт и сопряжение с PWM (0/Z)

* Звуковой микшер суммирует 4 голоса в 18-битной знаковой сетке с защитой от переполнения (Saturation / Hard Limiter) в диапазоне `[-32768, +32767]`.
* **Преобразование в ШИМ:** Модуль `pwm.sv` ожидает беззнаковое 16-битное число, где середина шкалы `16'd32768` соответствует нулевой точке аудиоколебания:
  ```systemverilog
  wire [15:0] unsigned_sample = signed_sample + 16'sd32768;
  ```
* **Аппаратный буфер вывода:** Вывод `AUD_PWM` обязан сохраняться в режиме Open-Drain (только `0` или `Z`):
  ```systemverilog
  assign AUD_PWM = aud_pwm_loc ? 1'bz : 1'b0;
  ```
  Выдача активной единицы `1'b1` категорически запрещена во избежание повреждения аналогового фильтра платы!

## 5. Междоменный буфер волны: Аудио ➔ VGA (CDC Visualizer)

Для передачи формы волны звука из звукового домена (`clk_audio`) в видеодомен (`pixel_clk`):
* **Память:** Двухпортовая BRAM (Dual-Port Distributed RAM / Block RAM) на 1024 слова по 16 бит.
* **Порт A (Запись, `clk_audio`):** Работает в режиме **Triggered Single-Sweep**:
  1. При стробе `phase_sync` (zero-crossing) автомат взводит триггер захвата.
  2. Записывает подряд ровно 800 сэмплов с адреса 0 по 799 по стробу `sample_valid`.
  3. По достижении 800-го сэмпла запись останавливается до получения флага готовности от VGA (нового кадра VSYNC), предотвращая разрывы и неполное заполнение буфера.
* **Порт B (Чтение, `pixel_clk`):** Адресуется горизонтальной координатой `pixel_x` (0..799). На следующем такте выдает значение сэмпла для отрисовки координаты $Y$.
