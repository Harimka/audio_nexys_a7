# ПОЛНАЯ АРХИТЕКТУРА СИСТЕМЫ: ПОЛИФОНИЧЕСКИЙ СИНТЕЗАТОР И UI-КОМПОНОВЩИК

Этот документ является **генеральной спецификацией** для всех разработчиков и ИИ-агентов. Он описывает устройство каждого модуля, потоки данных, протоколы межмодульного взаимодействия и принципы синтезируемой реализации на **SystemVerilog** под ПЛИС Artix-7 (Nexys A7-100T).

## 2. Модуль 1: Входной роутер (`input_event_router.sv`)

Собирает события от разных источников (клавиатура, секвенсор, кнопки) и транслирует их в единый канонический формат:

```systemverilog
typedef struct packed {
    logic       valid;       // 1 такт: произошло событие
    logic       down;        // 1 = нажата, 0 = отпущена
    logic [6:0] note;        // 0..127 (номер ноты MIDI)
    logic [6:0] velocity;    // 1..127 (громкость / сила атаки)
    logic [2:0] wave_type;   // 0=Синус, 1=Пила, 2=Треугольник, 3=Квадрат
    logic [7:0] scancode;    // Физический скан-код (для иммунитета к октавным сдвигам)
} note_event_t;
```

## 3. Модуль 2: 4-голосный звуковой движок (`synth_engine.sv`)

### 3.1. Диспетчер голосов (`voice_allocator.sv`)
* Управляет 4 независимыми синтезаторными голосами (Voice 0..3).
* Назначает поступившую ноту на свободный голос.
* При нехватке голосов вытесняет голос в стадии Release либо самый старый голос с быстрым затуханием (Fast Release), исключая треск и клиппинг.
* Запоминает соответствие физической клавиши (scancode) и голоса, исключая зависание нот при смене октавы.

### 3.2. Генератор форм волны (`oscillator_core.sv`)
* Работает на частоте аудиодомена `clk_audio = 49.159 МГц` со стробированием сэмпла на частоте 48.006 кГц.
* 32-битный фазовый аккумулятор DDS.
* 4 формы волны:
  1. **Синус (Sine):** таблица 256 точек с четвертьволновой симметрией.
  2. **Пила (Sawtooth):** линейное нарастание `phase[31:16]`.
  3. **Треугольник (Triangle):** знаковая инверсия полупериода.
  4. **Меандр (Square):** двуполярный импульс `phase[31] ? +32767 : -32768`.

### 3.3. Огибающая громкости ADSR (`adsr_envelope.sv`)
* Фазы: Attack, Decay, Sustain, Release.
* 4 аппаратных пресета:
  - Пресет 1 (Piano): быстрая атака (5 мс), спад (200 мс), сустейн 40%, затухание 250 мс.
  - Пресет 2 (Strings/Pad): плавная атака (400 мс), длинный сустейн 80%, затухание 600 мс.
  - Пресет 3 (Pluck/Chiptune): сверхбыстрая атака (1 мс), спад (100 мс), сустейн 0%, короткое затухание 50 мс.
  - Пресет 4 (Organ): мгновенная атака (2 мс), сустейн 100%, быстрое затухание 10 мс.
* Мгновенный переход в Release при отпускании клавиши на любой фазе.

### 3.4. Насыщающий сумматор (`saturating_mixer.sv`)
* Суммирует 4 знаковых 16-битных сигнала в 18-битной сетке.
* Применяет аппаратный лимитер `[-32768, +32767]` и масштабирование мастер-громкости (16 уровней).
* Выход микшера смещается на `+16'sd32768` для получения беззнакового формата модуля `pwm.sv`.

## 4. Модуль 3: Междоменный буфер волны (`waveform_buffer.sv`)

Развязывает такты звука (`clk_audio = 49.159 МГц`) и такты видео (`pixel_clk = 39.941 МГц`):
* Построен на встроенной двухпортовой Block RAM (1024 слова по 16 бит).
* **Порт записи (Clock: `clk_audio`):**
  - Работает в режиме **Triggered Single-Sweep**: ожидает переход через ноль (`zero-crossing`) басовой ноты.
  - Записывает ровно 800 сэмплов с частотой 48.006 кГц, затем фиксирует буфер до завершения текущего кадра VGA.
* **Порт чтения (Clock: `pixel_clk`):**
  - Читает сэмпл по координате `pixel_x`. Учитывает аппаратную задержку чтения BRAM в 1 такт.

## 5. Модуль 4: Видеокомпоновщик и UI (`ui_compositor.sv`)

Рендеринг «на лету» (Beam Racing) в стандарте **SVGA 800×600 @ 60.2 Гц** (`pixel_clk = 39.941 МГц`, развертка 1056×628).

### Слои компоновщика (Z-Index):

| Слой | Модуль-виджет | Область экрана (Y) | Что рисует |
|---|---|---|---|
| **Слой 1 (HUD)** | `widget_text_hud.sv` | $Y: 10..60$ | Панель статуса: волна (SINE/SAW), пресет ADSR, октава, шкала громкости, активные ноты. Использует `font_rom.sv`. |
| **Слой 2 (Волна)** | `widget_oscilloscope.sv`| $Y: 65..360$ | Неоновый луч осциллографа с координатной сеткой. Отображает стоячую волну из `waveform_buffer.sv`. |
| **Слой 3 (Пианино)**| `widget_piano_keys.sv` | $Y: 375..530$ | Фортепианная клавиатура на 2 октавы с мягкой подсветкой активных нот. |
| **Слой 4 (Пасхалка)**| `widget_rickroll.sv` | Полноэкранный / окно | Зарезервированный видеоплеер анимации. |
| **Слой 0 (Фон)** | Базовый цвет | Весь экран | Темно-графитовый фон `0x112`. |

### Выравнивание конвейера (Pipeline Alignment):
Компоновщик содержит 1-тактный регистр задержки для сигналов `h_sync`, `v_sync`, `disp_enbl` и координат, что компенсирует латентность чтения BRAM/ROM и исключает смещение картинки.

---

## 6. Модуль 5: Память и Секвенсор мелодий (`sequencer_player.sv`)

* Хранит последовательность нот `{duration_ticks[15:0], note[6:0], velocity[6:0]}` в ROM.
* Автомат шагает по массиву и шлет события в `input_event_router`.
* Позволяет воспроизводить демонстрационные мелодии автономно без участия ПК.
