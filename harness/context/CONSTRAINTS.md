# РЕЕСТР ОГРАНИЧЕНИЙ И ЗАПРЕТОВ ПРОЕКТА (CRITICAL CONSTRAINTS)

Этот документ является **абсолютным законом** для всех разработчиков и ИИ-агентов (Antigravity, Codex и др.). Любое предложение, нарушающее данные правила, подлежит немедленной отбраковке.

## 2. Категорические архитектурные запреты

1. ❌ **MicroBlaze СТРОГО ЗАПРЕЩЕН:**
   * Никаких софт-процессоров MicroBlaze в проекте быть не должно (условие хакатона).
2. ❌ **Vivado Block Design (IP Integrator) СТРОГО ЗАПРЕЩЕН:**
   * Проект собирается исключительно на чистом RTL (SystemVerilog/Verilog) через скрипты Tcl/Makefile.
3. ❌ **Запрет сторонних Vivado IP вне белого списка:**
   * Разрешены **только 5 встроенных IP-ядер**:
     1. `Clocking Wizard` (генерация частот)
     2. `Block Memory Generator` (BRAM для ROM/памяти сэмплов)
     3. `Distributed Memory Generator` (LUT RAM/ROM)
     4. `MIG (Memory Interface Generator)` (для внешней DDR2, если потребуется)
     5. `AXI Crossbar (AXI XBAR)` (для арбитража шин)
   * **Любые другие IP Vivado (включая ILA, VIO, FIFO Generator, DSP Compiler, AXI DMA и т.д.) ЗАПРЕЩЕНЫ без подтвержденного разрешения эксперта.**

## 3. Электробезопасность и аппаратные правила

1. ⚠️ **Аудиовыход `AUD_PWM` (КРИТИЧЕСКИ ВАЖНО):**
   * Вывод `AUD_PWM` подключен к однополярному аналоговому фильтру платы.
   * **Сигнал `AUD_PWM` разрешено переводить ТОЛЬКО в `0` (`1'b0`) или в третье состояние `Z` (`1'bz`).**
   * **СТРОГО ЗАПРЕЩЕНО выдавать активную единицу `1'b1`!** (Это может повредить выходной каскад усилителя платы).
2. **Формат аудиосэмплов:**
   * Signed PCM масштабируется относительно нуля и преобразуется в unsigned PWM.
   * Частота дискретизации: ~48,006.5 Гц (10-битный PWM, тактовая частота аудио ~49.152 МГц).
3. **VGA Видеосистема:**
   * Разрешение: **800×600 @ 72 Гц** (тактовая частота пикселей `clk_vga = 50.0 МГц`).
   * **ЗАПРЕЩЕНО копировать параметры 640×480 из учебных методичек!** Тайминги гашения, синхроимпульсов и активной зоны должны строго соответствовать стандарту 800×600.
4. **Clocking Wizard (`clk_wiz_0`):**
   * Запрещено менять коэффициенты умножения/деления MMCM/PLL без полного пересчета всех зависимых таймеров, фазовых аккумуляторов DDS и горизонтальных/вертикальных счетчиков VGA.

## 4. Инженерные правила RTL-кода

1. **Протокол передачи данных (Streaming Handshake):**
   * Все сэмплы и поток данных передаются строго по контракту `valid && ready`.
   * При наличии backpressure (`!ready`) источник **обязан удерживать данные и фазу** без потерь и смещений.
   * Обязательно учитывать латентность BRAM (1–2 такта).
2. **Clock Domain Crossing (CDC):**
   * Передача многобитных шин между доменами (например, `clk_audio` ↔ `clk_vga` ↔ `sys_clk`) через простые двухтриггерные цепочки (2-FF) **ЗАПРЕЩЕНА**, так как они не гарантируют целостность шины.
   * Требуется: согласованный 4-фазный handshake, асинхронное FIFO на кодах Грея или протокольная двухпортовая память.
   * Ограничения `set_clock_groups -asynchronous` в файле XDC не устраняют аппаратные метастабильные ошибки.
3. **Сброс (Reset Integrity):**
   * При потере захвата PLL (`locked == 1'b0`) сигнал `rst_n` обязан немедленно и синхронно переходить в активный сброс (`0`).
   * Снятие сброса должно быть синхронизировано с тактовым доменом соответствующего модуля.
4. **Светодиоды и индикаторы:**
   * Для медленных сигналов и развертки семисегментника предпочитать сигналы разрешения такта (**clock enable**), а не создавать делители с выходом на тактовые входы логики.

## 5. Правила открытого кода и сторонних компонентов

1. Сторонний открытый код разрешен, но **каждый компонент обязан быть задокументирован**:
   - URL репозитория и точный commit / версия.
   - Реальная лицензия (Apache 2.0, MIT, BSD). **Запрещено выдумывать лицензии!**
   - Назначение, внесенные изменения и способ верификации.
2. Не заявлять поддержку SD-карт, WAV, MP3 или MIDI, пока она фактически не написана в RTL и не верифицирована тестами.

## 6. Организационные правила репозитория

1. **Zero-Touch и владение файлами:**
   * Один владелец на каждый модуль. Чужой код не затирать.
   * Файлы `src/top/`, `src/top/audio_nexys_a7.xdc`, `src/tcl/deploy.tcl`, `Makefile` изменяет только Интегратор.
2. **Гигиена репозитория:**
   * **Никогда не коммитить:** временные папки Vivado (`vivado/`, `.Xil/`, `*.jou`, `*.log`), сборку Verilator (`obj_dir/`), скомпилированные битстримы (`*.bit`), личные файлы и токены.
