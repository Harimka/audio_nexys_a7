# Происхождение и лицензии

Основа — предоставленный владельцем `audio_nexys_a7.zip`, описанный его README как демо организаторов учебного хакатона. Исходный README сохранён в `doc/BASELINE_README.md`, контрольные суммы — в `doc/BASELINE_MANIFEST.json`.

В начальном состоянии RTL, XDC, Tcl, исходные Makefile, IP и материалы были сохранены без изменения. Для MIDI-стендового прототипа RTL top/XDC расширены UART-входом, добавлены собственные UART RX, MIDI parser, синусный wavetable, Python-мост и тесты. Базовые Vivado IP/проектные файлы не заменялись. README корня описывает текущее состояние.

Общий LICENSE в исходном ZIP отсутствует. Не приписывать всем файлам MIT/Apache или другую лицензию. Публикация по поручению владельца не устанавливает новую лицензию третьих лиц.

## Указания в исходниках

- `src/sim/Makefile`: Project F / Will Green, 2023, MIT-атрибуция, https://projectf.io/posts/fpga-pong/ . Это не общая лицензия всех файлов.
- `src/rtl/sber_logo_rom.sv`: изображение из `sberday_nexys_a7_svga`. Точная ссылка и лицензия изображения в ZIP не установлены; указание сохранено.
- `doc/nexys-a7_rm.pdf`: руководство Digilent с собственными уведомлениями об авторских правах. Остальные PDF/изображения — материалы исходного пакета, их права этим документом не заменяются.
- Clocking Wizard/Vivado: действуют условия производителя. Здесь конфигурация IP, не установка Vivado.

Добавлены анализ, инструкции ИИ, задачи агентов, AGENTS.md, требования, аудит Icarus, логи и manifest. Подготовлены с использованием ИИ; выводы сопровождаются проверками и ограничениями. Это не реализация итогового плеера.

## Будущие заимствования

Для каждого компонента фиксировать: URL, версию/commit, лицензию, файлы применения, изменения команды и команды/результаты проверок. Источники требуется указать эксперту в Telegram и в презентации; этот документ не заменяет оба действия команды.

Личные фотографии, серийные номера и коды регистрации оборудования из переписки не включены.

## Просмотренный UART-справочник

Пользователь указал [YuraThomas/Methoda, UART_up](https://github.com/YuraThomas/Methoda/tree/main/Interfaces/My_UART/UART_up), revision `80b2d908b18afbe6623da05266936f8ac58cc8e7`, MIT. Модуль был просмотрен как учебный пример FSM UART; HDL исходники не копировались и не модифицировались из этого репозитория. Реализация этого проекта написана отдельно и покрыта собственным Icarus тестом. Python-пакеты `mido`, `python-rtmidi`, `pyserial` устанавливаются пользователем и в репозиторий не вендорятся.
