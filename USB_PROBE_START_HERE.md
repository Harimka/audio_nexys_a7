# Проверка MicroLab на индикаторе платы

Это исходники отдельной диагностики, не готовый bitstream. Полная инструкция: [diagnostics/usb_host_probe/README.md](diagnostics/usb_host_probe/README.md).

1. Распаковать ZIP целиком.
2. Открыть Vivado → Tcl Console. Выполнить, подставив свой путь:
   ```tcl
   source /home/user/audio_nexys_a7/diagnostics/usb_host_probe/build.tcl
   ```
3. После успешной сборки: Open Hardware Manager → Open Target → Auto Connect → Program Device.
4. Выбрать `audio_nexys_a7/build/usb_host_probe/usb_host_probe.runs/impl_1/audio_nexys_a7.bit`.
5. MicroLab в USB HOST платы, PROG/UART платы в ноутбук. Диагностика звука не выдаёт.
6. SW0 и SW1 вверх: должен появиться `12345678`. Затем оба вниз, нажать CPU RESET, нажимать клавиши MicroLab. Записать, меняются ли цифры.

Первые четыре цифры в основном режиме — счётчик корректных кадров, последние четыре — два последних байта. Пока формат реального входа не установлен, это не обязательно номера нот. Полная расшифровка всех страниц/LED — в инструкции.

Проект отделён от исходного аудиодемо, новых Vivado IP нет, PIC24 не перепрошивается. Здесь подтверждена только симуляция; результат на плате и Vivado-сборка пока не проверены. Ничего не опубликовано в GitHub этим диагностическим обновлением: пользователь попросил локальный архив.
