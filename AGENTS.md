# Правила для агентов

Перед изменениями прочитайте `README.md`, `doc/REQUIREMENTS.md`, `doc/AGENT_TASKS.md`, релевантные части `doc/ANALYSIS.md` и `tests/audit/README.md`.

## Ограничения

- SystemVerilog/Verilog, top `audio_nexys_a7`, part `xc7a100tcsg324-1`.
- MicroBlaze и Block Design запрещены.
- Разрешённые Vivado IP: Clocking Wizard, Block Memory Generator, Distributed Memory Generator, MIG, AXI XBAR. Не добавлять остальные, включая отладочные, без подтверждённого разрешения.
- Сторонние компоненты документировать: URL, версия/commit, лицензия, применение, изменения и проверки. Не придумывать лицензию.
- Не заявлять SD/MP3/MIDI или работу на плате без соответствующей реализации и проверки.
- Срок и подробные критерии неизвестны. Предположения не выдавать за требования.

## Организация работы

План `doc/AGENT_TASKS.md` предназначен для разработки несколькими агентами, когда пользователь её запускает и среда поддерживает делегирование. Само наличие файла не требует создавать чаты или начинать реализацию без запроса.

Один владелец на каждый набор файлов. Общие top, XDC, Tcl, Makefile и интерфейсы изменяет интегратор; исполнители передают ему контракт и пример подключения. Не затирать чужие правки. Локальную ошибку исправлять локально.

Правило раскрытия источников не является командой немедленно писать эксперту. Подготовьте сведения для команды; отправка сообщений, публикация и прошивка требуют соответствующего поручения пользователя.

## Инженерные правила

- Для каждого порта указать домен, reset, формат и задержку.
- Приём сэмпла — `valid && ready`; при backpressure данные удерживаются. Учитывать латентность ROM/BRAM.
- Для многобитного CDC нужен согласованный handshake, корректный async FIFO или подходящая память с протоколом. Два FF на каждый бит не обеспечивают атомарность шины. Clock groups в XDC не исправляют CDC.
- Сохранять аппаратный `AUD_PWM` как 0/Z. Signed PCM масштабировать относительно нуля и затем переводить в unsigned PWM.
- Предпочитать clock enable новому такту из обычной логики для индикаторов.
- Не переносить параметры 640×480 из методички в текущий 800×600.
- Не менять Clocking Wizard без пересчёта зависимых частот.
- Не коммитить сгенерированные файлы Vivado/Verilator, битстримы, секреты, личные фото и коды регистрации.

## Проверки и отчёт

`python3 tests/audit/run_audit.py .` запускает baseline-аудит. Reset/VGA тесты **ожидают дефекты**; после исправлений нужны проверки правильного поведения, а не просто зелёный baseline. Не менять ожидания ради зелёного результата без утверждённого требования.

Clock stub проверяет только порты/иерархию. Icarus не заменяет MMCM, Verilator/SDL, Vivado, timing/CDC analysis или стенд.

Результат агента: проблема и новое поведение; изменённые файлы; команды и факты проверок; влияние на интерфейсы/домены; непроверенное и следующий шаг интеграции. Решение должно быть объяснимо командой на защите.
