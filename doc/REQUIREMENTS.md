# Требования и неизвестные

## Подтверждено

Цель исходного README — музыкальный плеер на базе демо для Nexys A7-100T. Проект использует `xc7a100tcsg324-1`, фото подтверждает 100T CSG324.

MicroBlaze, Block Design и Vivado IP вне исключений запрещены. Исключения: Clocking Wizard, Block Memory Generator, Distributed Memory Generator, MIG, AXI XBAR.

Открытый код разрешён с учётом лицензий и указанием источников эксперту в Telegram и в презентации. Оценивается вклад команды: интеграция, доработка, отладка. ИИ разрешён, учитывается понимание.

| Часть | Максимум | Множитель |
|---|---:|---|
| Звук | 45 | K₁ |
| VGA | 25 | K₂ |
| Периферия | 20 | K₃ |
| Презентация | 10 | Нет |

Итог = звук × K₁ + VGA × K₂ + периферия × K₃ + презентация. Правила назначения K неизвестны.

## Уточнение пользователя, 2026-10-24

MicroLab подключается к плате, наушники — к MONO AUDIO OUT. Ноутбук нужен только для прошивки; передача нот через него во время игры исключена. Плата сама превращает MIDI Note On/Off в звук методом таблично-волнового синтеза. Из доступных кабелей контроллера есть только USB. Текущий ноутбучный мост требование не выполняет. Прямой USB-MIDI вход требует проверки потенциального ограничения стандартной PIC24 firmware: см. `PROJECT_CONTEXT.md` и `DIRECT_USB_MIDI.md`. Фактическая firmware неизвестна; отсутствие MIDI на ней не измерено.

## Нужно уточнить

1. Срок сдачи, доступ к стенду и состав команды.
2. Подробную шкалу: `doc/criteria.md` отсутствует в архиве.
3. Обязательность SD/WAV/MP3, MIDI, полифонии и визуализации.
4. Допустимость предварительной подготовки файлов; ПК в рабочем тракте пользователь исключил.
5. Полные USB descriptors MicroLab и фактический путь PIC24→FPGA; модель MicroLab mk3 подтверждена lsusb. Дополнительного host/программатора у команды сейчас нет.
6. Результат звука и новой MIDI-сборки на стенде. На фото указан Vivado 2024.1; Programmed подтверждён для прежнего архивного bitstream.

ROM-мелодия пока только промежуточный вариант, не гарантированно достаточная сдача. Альтернативное открытое CPU-ядро потенциально допустимо по слайду, но CPU не обязателен. Разрешение AXI XBAR не разрешает все AXI IP.

Новые ответы фиксировать с источником/датой, разделять обязательное и желательное, указывать наблюдаемый способ проверки. Ограничения поддерживаемых форматов честно показывать в README и интерфейсе. Не придумывать численные баллы.
