# VGA-интерфейс: карта функций и план соответствия

## Источники и ветки, просмотренные при проектировании

- `release` (`8e0f374`): клавиатурный ввод C–B в четырёх октавах, монофонический активный голос и кнопки демо-синтезатора. Описание: `doc/KEYBOARD_NOTE_SYNTH.md`.
- `feature/keyboard-note-synth` (`e7839ef`): те же ряды клавиш и до восьми независимых голосов с независимым Note Off. Описание: `doc/KEYBOARD_NOTE_SYNTH.md`.
- `future` (`d32672a`): четыре регистровые дорожки нотных событий, выбор дорожки, запись/воспроизведение и транспортные команды. Это MIDI-события в регистрах; PCM/WAV/MP3 и SD-запись в этой ветке отсутствуют. Описание: `doc/MUSIC_RECORDING.md`.

## Соответствие функций интерфейсу

| Функция проекта | Существующий источник состояния | Элемент VGA | Ограничение отображения |
|---|---|---|---|
| Четыре нотных ряда C–B по октавам | `note_index`, `note_octave`, PS/2 make/break | Пиано-ролл: строки C1–B4; записанные ноты выбранной дорожки отмечаются синими блоками | Визуальный просмотр дорожки показывает первые 16 записанных Note On; регистровая запись хранит до 64 событий (до 32 пар) |
| Выбранная из четырёх дорожек | `selected_track`, `melody_event_count[]` | Заголовок пиано-ролла, выделение дорожки и список T1–T4 | Переключение: Tab/F10 вперёд, Backspace назад; выбор во время записи заблокирован |
| Запись Note On/Off | `melody_recording[]` | Мигающая красная REC-точка и REC для выбранной дорожки; статус каждой дорожки | Не является записью аудиосэмплов или WAV |
| Воспроизведение дорожек | `melody_playing[]` | PLAY для активного воспроизведения | Отображается фактический статус секвенсора, не статус демо-кнопки |
| События выбранной дорожки | `melody_recorder` хранит Note On/Off и межсобытийные sample deltas | Пиано-ролл: 28 высот × 16 временных шагов; соседние занятые ячейки формируют блок длительности, пустые ячейки — паузы, несколько высот видны одновременно | VGA-проекция имеет шаг 12000 выходных сэмплов (около 0,25 с при штатной частоте, 16 шагов/около 4 с); запись и воспроизведение остаются сэмпл-точными. События за пределом 16-шагового окна обрезаются только на экране |
| Синус, треугольник, квадрат, пила | `waveform_select` в аудиодомене | Имя формы и расчётное осциллографическое превью | Превью вычисляется на FPGA по той же фазовой форме; это не измеренный выходной аудиобуфер |
| Текущая нота и октава | клавиатурный note stack | Крупная нота, например C3; `--`, когда нет удерживаемой ноты | При аккорде показана последняя активная нота; звук остаётся полифоническим |
| Громкость | `volume[3:0]` | VU-полоска с 16 уровнями | Только цифровое положение регулятора, без измерения аналогового уровня |
| Управление | PS/2 декодер и `button_ctrl` | Подсказки внизу экрана | На клавиатуре: F9/Space REC, Enter PLAY, Esc STOP, Tab/F10 next track, Backspace previous track, стрелки — форма. На плате BTNC — демо Play/Pause, BTNL/BTNR — демо-нота, BTNU/BTND — громкость. |

## Отличия макета от фактических назначений

Переданный JSON предлагает BTNU для записи, BTNC для Play/Pause, SW[4:3] для волны и SW[2:0] для октавы. В просмотренных RTL/документации это не реализовано так: запись и дорожки управляются PS/2-командами; форму волны в текущей рабочей версии переключают стрелки; ряды клавиатуры уже задают октаву. SW[2:0] остаётся октавой только для демо-tone_generator. Поэтому интерфейс не рекламирует SW как текущий выбор волны/октавы и показывает реальные назначения.

JSON также упоминает MIDI через UART RX на C4. Этот путь не является текущим автономным источником нот для Nexys USB HOST. VGA использует подтверждённый в проекте PS/2-клавиатурный путь.

## Стиль и реализация

Разрешение 800×600, RGB444, светлый фон и сетка, тёмные подписи, синие активные ноты/выбранные элементы и красный индикатор записи. Используется штатный `font_rom.sv` (8×8 латиница/цифры/основные знаки), масштаб 2× для подписей и 4× для крупной ноты. Новые шрифты, Vivado IP и Block Design не добавляются.

Состояние аудиодомена передаётся в pixel-домен как стабильный snapshot с toggle handshake: payload фиксируется до смены toggle и остаётся неизменным до следующего обновления. Синхронизируются toggle и сам snapshot снимается после двух тактов pixel clock. Снимок включает 4 дорожки статуса/счётчиков, краткое превью Note On и 448-битную готовую матрицу выбранной дорожки. Recorder строит матрицу отдельно и публикует её после завершения проекции.

## Обновление интерфейса и piano-roll, 2026-10-24

HTML-макет [`fpga_daw_interface_concept.html`](ui_concept/fpga_daw_interface_concept.html) сохранён в проекте как визуальный ориентир: шапка транспорта, нотная сетка, справа форма волны/монитор/роутинг и строка подсказок. Макет содержит демонстрационные BPM, MIDI/UART и примерные ноты; RTL не выдаёт их за состояние платы. Показатели берутся из подключённых регистров и PS/2-декодера.

Во время записи сетка не обновляется. После остановки recorder обходит события, суммирует sample deltas, сопоставляет Note On с Note Off по идентификатору клавиши и строит матрицу целиком; удержанная при остановке нота заканчивается по времени остановки. Один шаг экрана соответствует примерно 0,25 с при частоте сэмплов около 48 кГц — шестнадцатая при 120 BPM. Сырые события и аудиовоспроизведение не квантуются. Матрица передаётся в VGA одним завершённым snapshot.

Точный playhead и настраиваемый BPM пока не реализованы. Экран показывает 16-шаговое окно, а не произвольную длину композиции; для длинных паттернов понадобятся прокрутка/масштаб времени и позиция воспроизведения.
