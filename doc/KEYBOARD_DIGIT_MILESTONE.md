# Промежуточный этап: цифры USB-клавиатуры на индикаторе

Статус: **проверено в RTL-симуляции и пользователем на реальной Nexys A7**. По сообщению пользователя, все цифры работают; значение меняется при нажатии, активен один разряд, остальные погашены. Звук на этом этапе не реализуется.

## Что реализовано

- USB-клавиатура подключается к USB HOST J5. PIC24 платы переводит поддерживаемый Boot HID ввод в PS/2; FPGA принимает PS/2 Set 2 на `PS2_CLK`/`PS2_DATA`.
- Верхний цифровой ряд и цифровой блок распознаются как цифры 0–9.
- Последняя нажатая цифра сохраняется после отпускания клавиши.
- Показывается только разряд `AN[0]`; остальные семь разрядов выключены.
- На этом шаге не выполняется назначение музыкальных нот, звуковой синтез или воспроизведение мелодии.

## Где находится реализация

Реализация и проверки лежат в ветке `feature/keyboard-digit-display`:

- `src/rtl/ps2_keyboard_digit.sv` — синхронизация/фильтрация PS/2, чтение кадра и таблица Set 2 scan code → decimal digit.
- `src/rtl/sevseg_ctrl.sv` — мультиплексирование индикаторов и маска `digit_mask` для выключения разрядов.
- `src/top/audio_nexys_a7.sv` — подключение PS/2 decoder к top, показ последней цифры на `AN[0]`.
- `src/top/audio_nexys_a7.xdc` — PS/2 pins F4/B2 и pull-ups.
- `tests/keyboard/` — тесты цифр и однозначного включения `AN[0]`.
- `tests/audit/run_audit.py` — общий запуск регрессионных симуляций.

Числовой ряд (Set 2): `1=16`, `2=1E`, `3=26`, `4=25`, `5=2E`, `6=36`, `7=3D`, `8=3E`, `9=46`, `0=45` (значения hex). Keypad scan codes также есть в case statement `ps2_keyboard_digit.sv`.

Упрощённо логика mapping выглядит так:

```systemverilog
case (scan_code)
  8'h16: digit <= 4'd1;
  8'h1E: digit <= 4'd2;
  // ...
  8'h36: digit <= 4'd6;
  // ...
  8'h46: digit <= 4'd9;
  8'h45: digit <= 4'd0;
  default: ;
endcase
```

`digit_mask = 8'h01` включает только `AN[0]`; нулевые биты маски гасят соответствующие позиции. Decoder игнорирует `F0` break prefix и extended `E0` коды для обновления цифры.

## Проверки и ограничения

Icarus audit: `python3 tests/audit/run_audit.py .`. Проверяются top row/keypad digits 0–9, PS/2 break/extended filtering, семисегментная маска. Пользователь дополнительно подтвердил, что цифры все работают на плате.

Никакая оценка генерации звука из клавиатуры из этого результата не следует. Следующий этап — выбрать mapping клавиш к нотам/октавам и соединить события нажатия/отпускания с wavetable и аудиовыходом платы.
