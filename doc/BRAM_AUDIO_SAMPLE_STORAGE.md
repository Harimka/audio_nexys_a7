# Сохранение и воспроизведение звукового файла во встроенной памяти BRAM (Block RAM)

> **Ветка:** `feature/sample-memory-player`  
> **Целевая платформа:** Xilinx Artix-7 `xc7a100tcsg324-1` (Nexys A7-100T)  
> **Тип памяти:** Аппаратный **Block RAM (BRAM)** (блоки RAMB36E1/RAMB18E1)

---

## 1. Архитектурное решение: Почему и как используется BRAM

На плате Digilent Nexys A7-100T установлена ПЛИС Artix-7 `xc7a100tcsg324-1`, содержащая **4,860 Кбит блочной памяти (135 блоков BRAM по 36 Кбит каждый)**. Это позволяет сохранять аудиосэмплы непосредственно на кристалле без использования внешних микросхем или сложных контроллеров.

```mermaid
flowchart TD
    WAV[Audio File .wav / Synth] -->|tools/wav_to_mem.py| MEM[sample_data.mem\n4096 слов по 16 бит]
    MEM -->|Инициализация $readmemh| BRAM["Аппаратный BRAM (RAMB36E1/18E1)\naudio_sample_rom.sv\n(* ram_style = 'block' *)"]
    
    subgraph Engine["Контроллер воспроизведения (audio_sample_player.sv)"]
        FSM[Автомат управления:\nIDLE -> PRE -> PLAY]
        EN_CTRL[Комбинационный строб rom_en:\nrom_en = ready && valid]
        ADDR[Счётчик sample_addr: 0..4095]
    end

    BRAM -->|dout[15:0] латентность 1 такт| FSM
    EN_CTRL -->|en| BRAM
    ADDR -->|addr| BRAM
    
    FSM -->|sample_out[15:0]\nvalid| FIFO[Audio FIFO 256 samples]
    FIFO -->|ready| EN_CTRL
    FIFO --> PWM[PWM Модулятор 48 кГц\nAUD_PWM open-drain 0/Z]
```

### Ключевые требования к реализации в BRAM:
1. **Директива синтеза `(* ram_style = "block" *)`:**
   В модуле `audio_sample_rom.sv` память объявлена с явным атрибутом стиля, что гарантирует синтез Vivado в BRAM, а не в распределённую LUT-память:
   ```systemverilog
   (* ram_style = "block" *) reg [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];

   always_ff @(posedge clk) begin
       if (en)
           dout <= mem[addr];
   end
   ```
2. **Аппаратный строб `en` (Clock Enable BRAM):**
   В кристаллах 7-Series примитивы Block RAM имеют аппаратный вход разрешения `en`. Когда `en == 0`, выходные триггеры BRAM удерживают предыдущее значение (`dout` заморожен). Это используется для идеальной реализации backpressure!
3. **Латентность чтения:**
   Чтение из BRAM является синхронным и занимает ровно 1 такт: адрес выставляется на такте $T$, данные готовы на такте $T+1$. Автомат модуля `audio_sample_player` компенсирует эту задержку состоянием предварительной загрузки `ST_PRE`.

## 2. Безопасная обработка Backpressure (`ready && valid`)

Согласно правилам проектирования `AGENTS.md`: *«Приём сэмпла — `valid && ready`; при backpressure данные удерживаются. Учитывать латентность ROM/BRAM»*.

* **Когда FIFO готово принять сэмпл (`ready == 1`):**
  Строб `rom_en` активен, BRAM считывает следующий сэмпл, счётчик `sample_addr` инкрементируется.
* **Когда FIFO заполнено (`ready == 0`):**
  Строб `rom_en` снимается комбинационно (`assign rom_en = ... && ready`). BRAM немедленно прекращает чтение, адрес не инкрементируется, текущее значение `sample_out` остаётся строго неизменным.
* **Результат:** Ни один сэмпл не пропускается и не затирается, форма сигнала не искажается.

## 3. Утилита подготовки данных (`tools/wav_to_mem.py`)

Для преобразования аудиофайлов в hex-формат для BRAM разработана консольная утилита:
```bash
# Конвертация существующего WAV-файла (16 бит, моно):
python tools/wav_to_mem.py sound.wav -o src/rtl/sample_data.mem -n 4096

# Генерация чистого синтетического сэмпла колокольчика (A4 440 Гц + обертоны 880 и 1320 Гц):
python tools/wav_to_mem.py --synth -o src/rtl/sample_data.mem -n 4096
```

Формат файла `sample_data.mem`:
- Шестнадцатеричные 16-битные слова, по одному на строку (например, `8000`, `802C`, `80B1`...).
- Формат: offset-binary (0..65535, середина тишины — `32768` / `16'h8000`), напрямую согласованный с аудиомодулятором ШИМ (`pwm.sv`).

## 4. Управление и проверка на плате

* `SW[0] = 1`: активация режима воспроизведения из BRAM (вместо DDS синтезатора).
* `BTNC`: запуск воспроизведения звука с начала (адрес 0).
* `SW[1]`: переключатель режима:
  * `SW[1] = 0` — одиночный прогон (One-shot, завершается с переходом в тишину).
  * `SW[1] = 1` — циклический режим (Loop, бесшовный переход с 4095 на 0 сэмпл).
* `BTND`: остановка проигрывания.
* `BTNU / BTND`: цифровая регулировка громкости.
