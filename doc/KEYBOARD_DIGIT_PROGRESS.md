# Статус промежуточной цели: клавиатурные цифры

**Результат подтверждён пользователем на физической Nexys A7:** нажатия клавиш `0`–`9` отображаются на одном семисегментном разряде, значение меняется, остальные разряды выключены. В начале теста была путаница с действиями; пользователь повторно подтвердил, что цифры все работают.

Исходники реализации не в `main`, а в отдельной ветке **`feature/keyboard-digit-display`**, commit `51b8439`. Чтобы проверить или продолжить эту реализацию, переключитесь на эту ветку.

## Где код

- `src/rtl/ps2_keyboard_digit.sv` — PS/2 Set 2 приёмник, который распознаёт цифры верхнего ряда и keypad.
- `src/rtl/sevseg_ctrl.sv` — индикаторный контроллер с маской разрядов.
- `src/top/audio_nexys_a7.sv` — интеграция: последняя цифра выводится на `AN[0]`.
- `src/top/audio_nexys_a7.xdc` — PS/2 `CLK`/`DATA` на FPGA pins F4/B2.
- `tests/keyboard/` — тесты декодера и маски индикатора.
- `doc/KEYBOARD_DIGIT_MILESTONE.md` в feature-ветке — подробное описание реализации.

PIC24 платы принимает поддерживаемую USB HID-клавиатуру через USB HOST и представляет поток FPGA как PS/2. RTL сопоставляет Set 2 make codes с цифрами. Например:

```systemverilog
case (scan_code)
  8'h16: digit <= 4'd1;
  8'h1E: digit <= 4'd2;
  8'h36: digit <= 4'd6;
  8'h46: digit <= 4'd9;
  8'h45: digit <= 4'd0;
  default: ;
endcase
```

Разрядная маска `8'h01` оставляет включённым только `AN[0]`; остальные разряды выключены. Точная таблица всех цифр и keypad mapping находится в `ps2_keyboard_digit.sv`.

## Проверки и границы результата

В feature-ветке запускались `python3 tests/audit/run_audit.py .` и `git diff --check`; симуляции прошли. Пользователь отдельно подтвердил работу цифр на плате. Это закрывает только ввод и отображение цифр: ноты, октавы, запуск wavetable и слышимый звук ещё не подтверждены.

Roadmap и полный журнал контекста доступны в `doc/ROADMAP.md`, `doc/PROJECT_CONTEXT.md` и `doc/CHAT_LOG.md` в feature-ветке. Ограничения Vivado из `AGENTS.md` остаются актуальны.
