# Прямой MicroLab → Nexys A7 → наушники

Требование пользователя (2026-10-24): ноутбук только для прошивки. При игре MicroLab передаёт MIDI-команды по USB непосредственно аппаратной системе, FPGA генерирует звук, наушники подключены к MONO AUDIO OUT.

## Проверенное ограничение

В [руководстве Digilent, разделы 7 и 7.1](https://digilent.com/reference/_media/reference/programmable-logic/nexys-a7/nexys-a7_rm.pdf) указано: J5 USB HOST обслуживает PIC24FJ128, штатно только Boot HID клавиатуры/мыши. В FPGA передаются PS/2 clock/data (F4/B2). MIDI-контроллер не является Boot HID клавиатурой.

[Схема Digilent, лист USB HID](https://digilent.com/reference/_media/reference/programmable-logic/nexys-a7/nexys-a7-sch.pdf) показывает USB D+/D− на PIC24FJ128GB106, а не непосредственно на FPGA. Поэтому USB host RTL в FPGA не получает физические USB-линии этого разъёма. UART C4 связан с FTDI PROG/UART и также не является выходом MIDI из J5.

В [ответе сотрудника Digilent от 2020-05-23](https://forum.digilent.com/topic/20152-reprogramming-nexys-4a7-pic-pic-firmware-source-code/) сказано, что исходники штатной PIC24 firmware не предоставляются. Это исторический ответ; рабочей открытой замены с USB-MIDI в рамках текущей проверки не найдено. Наличие J9 ICSP подтверждается схемой.

## Что уже есть в RTL

`midi_wavetable.sv`: 256-точечная таблица синуса, 32-битная фаза, 128 MIDI-нот, velocity, один голос. `midi_uart_receiver.sv`: UART MIDI Note On/Off и running status. Они не реализуют USB enumeration, descriptors, endpoint polling или USB-MIDI host. Выбранный UART вход на плате сейчас обслуживает только прежний стендовый мост. Ни прямой MicroLab, ни аналоговый звук новой версии на реальной плате пока не проверены.

## Реальные способы продолжить

1. **Сохранить кабель MicroLab в J5:** разработать отдельную firmware PIC24 USB-MIDI host и прошить PIC24 через J9 подходящим ICSP-программатором. Потребуются USB-host стек под этот PIC, enumeration USB-MIDI устройства, разбор descriptors и bulk IN MIDI event packets, передача событий в FPGA через доступные PS/2 линии с согласованным протоколом. Нужно проверить точные пины, конфигурационные биты, питание/VBUS, состояние линий FPGA configuration и восстановление исходной firmware. Vivado bitstream PIC24 не перепрошивает. Такого программатора/исходной firmware в доступном комплекте не подтверждено. Эта работа не выполнена; прошивать PIC24 наугад нельзя.
2. **Без изменения PIC24:** внешний USB-MIDI host с подтверждённой поддержкой MicroLab и выходом UART логических уровней, согласованных с FPGA, подключённым к Pmod. Нужны само устройство и провода. Переназначить UART на Pmod, согласовать baud и формат, затем проверить настоящие ноты. Обычный USB-UART адаптер host-функцию для MicroLab не выполняет. DIN-выход потребует отдельной MIDI-входной схемы, напрямую к FPGA его не подключать.

Оба маршрута позволяют обойтись без ноутбука во время игры. В имеющемся подтверждённом комплекте (Nexys A7 + MicroLab + USB-кабели + наушники) нет готового программно доступного USB-MIDI host. Полный прямой тракт пока заблокирован выбором и обеспечением одного из этих маршрутов. Не подменять его компьютерным мостом и не объявлять готовым на основании unit test синтезатора.

## Приёмка прямого тракта

После реализации выбранного host: запитать систему без ноутбука в тракте; проверить Note On, Note Off и Note On velocity=0; разные ноты и velocity; повторные нажатия; переподключение MicroLab без зависших нот; выход в MONO AUDIO OUT. Зафиксировать firmware/bitstream, схему подключения и реальные наблюдения. До этой проверки не писать, что MicroLab играет через J5.
